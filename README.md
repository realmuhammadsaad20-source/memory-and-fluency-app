# تطبيق بناء الذاكرة والتركيز والطلاقة اللفظية الأصيلة
## Flutter Application (Android Release Ready)

تطبيق متكامل مبني بفريمورك **Flutter** مع نظام أتمتة سحابي كامل عبر **GitHub Actions** لتوليد ملف الـ **APK** تلقائياً.

### 🌟 المكونات والميزات:
- **لعبة Dual N-Back التفاعلية:** تدريب الذاكرة العاملة بشبكة 3x3 وإشارات صوتية ومستويات متدرجة.
- **تثبيت التحديق البصري (90 ثانية):** شاشة تركيز ومؤقت تنازلي دقيق.
- **الارتجال الصوتي المتدفق (60 ثانية):** مولد موضوعات عشوائية لمنع كلمات الحشو.
- **قصف التشبيهات والمجاز السريع:** مولد مفاهيم لصياغة 3 تشبيهات في 45 ثانية.
- **سجل القياسات الأسبوعي:** مصفوفة لتتبع الـ N-Back وعدد الكلمات/دقيقة وسرعة التشبيهات.
- **المكتبة الكاملة:** شروحات الفصول العصبية والبيولوجية كاملة.

راجع ملف `دليل_التثبيت_خطوة_بخطوة.md` لمعرفة كيفية رفع المشروع والحصول على الـ APK.
